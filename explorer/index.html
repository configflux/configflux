ConfigFlux Model Explorer

static · local · read-only
Pick a file or drag one here — an inspect summary, cfx options list, resolved snapshot, or explain output. Samples live in explorer/fixtures/.

Load a model summary (compiler inspect … summary) or a facet-options list (cfx options --format json) to browse the component / facet / option structure.

Load a resolved snapshot (cfx resolve --format json) to see the hash lineage and the resolved parameters table.

Load an explain output (cfx explain --format json) to see the minimal conflicting-constraint set behind a rejected selection.

Renders ConfigFlux canonical JSON artifacts only. It never runs ConfigFlux, makes no network requests, and writes nothing. Works from file:// (Firefox / Safari) or any static file server.
